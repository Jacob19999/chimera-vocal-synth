# Orchestra recordings

Cello section, violin section, flute and oboe recordings from Versilian
Studios Chamber Orchestra 2 Community Edition. The upstream library is
dedicated to the public domain under CC0 1.0.

- [Versilian Studios source and licensing](https://versilian-studios.com/vsco-community/)
- [Pinned upstream sample archive](https://github.com/sgossner/VSCO-2-CE/tree/440300901dfe9275fd84e0b7763af1f8443ae62e)
- [Upstream CC0 license](https://github.com/sgossner/VSCO-2-CE/blob/440300901dfe9275fd84e0b7763af1f8443ae62e/LICENSE)

The bundled banks use the cello and violin sections' soft vibrato
sustains, the flute's soft non-vibrato sustains and the oboe's soft
sustains. Each bank contains 1.2-second mono clips at 22.05 kHz, with
a crossfaded sustain loop starting at 0.4 seconds. The clips retain
their recorded attacks and have been level-matched for the Opera mix.
